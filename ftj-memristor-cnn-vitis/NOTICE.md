# Notice

This repository is a technical archive and portfolio-oriented description of academic research associated with an FTJ-array neural-computing system.

## Source-code status

- `legacy/main.c` is a curated refactoring of a surviving experimental source snapshot. Its original Xilinx copyright and licence header is preserved.
- The workflow exposes, but does not fabricate, unavailable board drivers, hardware-platform files, model parameters, and data through an integration interface.
- Files under `src/core/` are explanatory refactorings written from the published equations and surviving program logic. They are not represented as the original code used to generate every published figure.
